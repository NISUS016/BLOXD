# bloxd-desktop App

Tauri v2 desktop application with React, TypeScript, Tailwind CSS, Zustand, and `@xyflow/react`.

## Responsibilities
- Zoomable nested architecture canvas (double-click drill-down + breadcrumbs + unified overview)
- Live milestone overlay synced with `.bloxd/` edits on disk
- Node Inspector drawer for specs and metadata
- Scoped Context Export (`Ctrl+Shift+C`) and Command Palette (`Ctrl+K`)
